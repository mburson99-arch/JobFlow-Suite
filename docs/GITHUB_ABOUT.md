# GitHub About

Use this content for the GitHub repository description and metadata.

## Short Description

Local-first job application tracker with Gemini resume tailoring, Gmail response monitoring, Chrome extension capture flow, and PDF resume export.

## Longer About

JobFlow Resume Tailor is a React/Express career workflow app built to capture job postings, tailor resumes with Gemini, export polished PDFs, and group Gmail responses under the correct application. The project documents the real engineering process: browser extension failures, Gmail parsing edge cases, resume formatting fixes, PDF export issues, and the cleanup from a clunky AI prototype into a more stable local-first tool.
